## How to Read This Guide

1. **FULL features** (✅): Open the feature → it works → number carries "Calculated (oracle-validated)" tag. No limits.
2. **PARTIAL features** (⚠️): Feature loads → user can interact → but result area notes "no oracle test" or "bypassed path"; use with awareness.
3. **STUB/LIMITATION/ORPHANED features** (⛏️/⚠️/❌): Feature loads or menu appears → but result says "not available", "under construction", or "infrastructure gap"; disclaimer banner visible.
4. **ABSENT features** (❌): Menu item does nothing; console error about unused imports; alternative path documented.

**No inflation:** Every limit is documented with the exact cause from the scorecard + verification audit. Features removed from the list to raise percentages do not appear.
